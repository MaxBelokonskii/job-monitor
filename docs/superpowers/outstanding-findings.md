# Замечания ревью: все закрыты

Перечень существовал только в переписке: спецификация подпроекта 2
ссылалась на «остальные тринадцать замечаний ревью и аудита подпроекта 1»,
не называя их. Сначала список был записан здесь, затем разобран целиком.

**Состояние проверено исполнением**, а не переписано по памяти — и это
дважды изменило картину: одно замечание оказалось закрыто попутно, два
других уже не воспроизводились, зато одно было сформулировано не о том.

## Закрыто попутно, до разбора

| № | Что было | Чем закрыто |
|---|----------|-------------|
| M-1 | `PATCH /api/presets/{id}` с нечисловой `position` давал 500 | при переписывании роута под M-2 (подпроект 2, задача 7): теперь 400 с объяснением |
| M-2 | тот же `PATCH` применялся наполовину: 422 возвращался уже после переименования | подпроект 2 — сначала проверяется всё, потом пишется всё |
| M-3 | файл резюме писался до строки в базе, а стирался до неё же | подпроект 2 — файл и строка появляются и исчезают вместе |

## Закрыто разбором

| № | Что было | Чем закрыто |
|---|----------|-------------|
| M-4 | `upload_resume` читал тело целиком в память | приём потоком: куски пишутся на диск по мере прихода, предел проверяется по ходу, расширение — до первого байта |
| M-5 | воркер, упавший сам между `running()` и `stop()`, давал 500 | `WorkerNotRunning` ловится: останавливать нечего — можно переключаться |
| M-6 | на 409 терялся список уже остановленных воркеров | названы в тексте отказа: иначе один воркер стоит, другой работает, и объяснения нет нигде |
| M-7 | сводка пресета отдавала `resume_id`, а не имя файла | рядом появился `resume_name`; битая ссылка даёт `None`, а не роняет список |
| M-8 | `file_path` из старых настроек отбрасывался вместе с резюме | файл забирается в библиотеку, пресет на него ссылается; непрочитанный или неподдерживаемый файл не срывает перенос остального |
| M-9 | заменить файл резюме было нечем | `PUT /api/resumes/{id}` плюс кнопка «Заменить»; идентификатор сохраняется, поэтому пресеты продолжают работать |
| M-10 | `PLACEHOLDERS` не читал никто, подсказка была написана руками | подстановки приходят из `/api/dictionaries`; тест проверяет, что каждая обещанная подстановка действительно выполняется |
| M-11 | `stored_name` уходил в ответ API | наружу не отдаётся: имя генерируется случайным затем, чтобы чужой файл нельзя было угадать |
| M-12 | `PATCH` принимал `{"name": 123}` и сохранял `"123"` | отказ 400; на создании то же самое даёт pydantic 2 без нашего участия |
| M-13 | проверка достижимости обработчиков ослаблялась | найден настоящий пробел: **кнопки, создаваемые кодом**, не проверялись вовсе — убери обработчик «Откликнулся» из карты, и кнопка молча перестала бы работать |

## Замечания аудита

Оба — «проверка держится за счёт соседней» — при повторной мутации
устояли на своём предмете: снятие защиты от повторного импорта отправок и
снятие записи о пропущенном секрете роняют именно те тесты, которые их
сторожат. Закрылись в ходе укрепления, отдельной правки не потребовалось.

## Что осталось намеренно

Политика хранения истории (`tg_found` и `worker_events` растут
неограниченно) и адаптивная вёрстка под узкие экраны — не замечания ревью,
а признанные границы области работ; они названы в спецификациях.

Обязательность проверок CI для слияния не включена — решение партнёра.
